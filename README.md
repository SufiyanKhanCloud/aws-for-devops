# AWS for DevOps

My practical AWS learning journey focused on building strong cloud fundamentals for DevOps and Cloud Engineering.

The goal is not simply to memorize AWS services or prepare for a certification.

The goal is to understand:

**Requirement → Architecture → AWS Services → Implementation → Security → Reliability → Cost → Operations**

## Learning Approach

I am following Abhishek Veeramalla's AWS / AWS Zero to Hero content as my primary learning path, while supplementing it with hands-on labs, AWS documentation, architecture exercises, troubleshooting, and practical DevOps scenarios.

My learning cycle is:

**Learn → Build → Break → Troubleshoot → Explain → Document**
